# Getting the APK

1. Open this repository on GitHub.
2. Click **Actions**.
3. Open **Build Android APK**.
4. Open the latest successful run.
5. Scroll to **Artifacts**.
6. Download **Tareq-Red-Thread-Android-APK**.
7. Unzip it to get the Android APK.

The current build is a debug APK intended for testing on your own Android device.
